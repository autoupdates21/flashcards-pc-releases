# FlashCards for Windows

Hebrew and English flash cards for children: make cards, play games, print double-sided cut-out cards.

**Download:** open [the latest release](https://github.com/autoupdates21/flashcards-pc-releases/releases/latest)
and click `FlashCards-Setup-<version>.exe` under *Assets*.

While installing, Windows may show "Windows protected your PC". Click **More info**, then **Run anyway**.
Once installed, FlashCards updates itself.

---

**הורדה:** פותחים את [הגרסה האחרונה](https://github.com/autoupdates21/flashcards-pc-releases/releases/latest)
ולוחצים על `FlashCards-Setup-<version>.exe` תחת *Assets*.

בהתקנה Windows עשוי להציג "Windows protected your PC". לוחצים **More info** ואז **Run anyway**.
אחרי ההתקנה התוכנה מתעדכנת לבד.

_This repository only holds the installers; each one is signed, and the program installs only signed updates._
